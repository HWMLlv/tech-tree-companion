# Screenshot sources

These images are native Obsidian window/region captures of Tech Tree Companion running in an isolated demonstration vault. They contain synthetic technology examples, not personal notes. Each language has its own cards and wheel labels. No rendered interface text was painted over after capture.

`wheel-*`: the shared dual-ring editor. `cards-*`: three SVG cards connected in Excalidraw. `node-*`: editing a demonstration card. `icons-*`: the grouped icon picker. `zh` and `en` indicate the plugin display language.

Host: Windows 11, Obsidian 1.13.7, Excalidraw 2.25.3. Captured from the bilingual candidate included in 0.4.32. Chinese/English interface selection does not translate saved custom content; examples were authored separately for each language.
